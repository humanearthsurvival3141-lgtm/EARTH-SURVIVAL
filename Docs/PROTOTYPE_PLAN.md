
# EARTH SURVIVAL — Prototype Plan

**Project:** EARTH SURVIVAL  
**Engine:** Unity  
**Language:** C#  
**Target platform:** Android  
**Camera:** Third-person  
**Development status:** Early prototype

## 1. Vision

Build a peaceful open-world survival game where players explore a natural environment, collect resources, manage survival needs, construct shelter, and complete missions.

The initial prototype focuses on core gameplay before advanced graphics, online services, or monetization.

## 2. Core Gameplay

- Explore forests, villages, cities, and mountains.
- Move using third-person controls.
- Collect food, water, wood, and stone.
- Manage health, hunger, thirst, and stamina.
- Find or use shelter.
- Complete timed missions.
- Unlock the next level after mission completion.
- Retry failed missions.
- Save and restore appropriate gameplay progress.

## 3. Design Principles

- No weapons or guns.
- No combat or player-versus-player gameplay.
- No item marketplace in the initial prototype.
- Prioritize exploration, survival, and resource gathering.
- Design touch controls for Android devices.
- Avoid promising earnings or financial rewards.

## 4. Prototype Milestones

### Milestone 1 — Project Setup
- Create the Unity project.
- Configure Android build settings.
- Organize scripts and assets.
- Set up the first test scene.

### Milestone 2 — Player
- Add a player character.
- Implement third-person movement.
- Configure the camera.
- Add mobile movement and jump controls.

### Milestone 3 — Survival Systems
- Implement health, hunger, thirst, and stamina.
- Add collectible food and water.
- Add resource inventory.
- Implement basic shelter interactions.

### Milestone 4 — Missions
- Add countdown timer.
- Implement mission success and failure.
- Add retry and checkpoint functionality.
- Unlock the next level after success.

### Milestone 5 — Environment
- Build a small test environment.
- Add terrain, trees, rocks, and simple structures.
- Optimize performance for Android.

### Milestone 6 — Saving and Testing
- Save required gameplay progress.
- Test mission and retry behavior.
- Test mobile controls and performance.
- Fix compile errors and gameplay bugs.

### Milestone 7 — Android Build
- Create an Android development build.
- Test on a physical Android device.
- Fix critical issues before considering public distribution.

## 5. Initial Success Criteria

The first playable prototype should allow a player to:

1. Start the game.
2. Move and look around.
3. Collect a resource.
4. Manage survival statistics.
5. Complete or fail a mission.
6. Retry after failure.
7. Unlock a subsequent level.
8. Run the test scene on Android.

## 6. Future Possibilities

Additional biomes, weather, expanded crafting, deeper shelter building, and further missions may be considered after the core prototype works.

Pi Network integration, online features, or rewards are not part of the initial prototype. Any future integration will depend on technical feasibility, platform rules, security, and applicable legal requirements.

## 7. Current Limitations

This plan describes intended functionality. Listing a feature here does not mean it has already been implemented or tested.

## 8. Definition of Done

A milestone is complete only when its implementation has been reviewed and the relevant functionality has been tested in Unity.
