
# EARTH SURVIVAL — Privacy Policy

**Last updated:** October 9, 2026

## 1. Introduction

EARTH SURVIVAL is an open-world survival game project under development using Unity.

This policy explains how privacy is intended to be handled in the current prototype and how it may change as the game develops.

## 2. Information Collection

The current prototype is not intended to require an account or personal information to play.

The actual information collected will depend on the features enabled in each build. If analytics, online services, accounts, advertising, or other third-party tools are added, this policy will be updated to describe the relevant data practices.

## 3. Local Game Data

The game may store gameplay information locally on your device, such as progress, unlocked levels, settings, and survival statistics.

Local save data may be removed if you uninstall the game or clear its application data.

## 4. Third-Party Services

The development project uses GitHub for source-code hosting.

If third-party services are integrated into a released game, their privacy practices and relevant links will be provided where appropriate.

## 5. Children's Privacy

The game is under development. Its intended age rating and any additional protections for younger players will be assessed before release.

## 6. Data Security

Reasonable measures will be considered to protect any personal information processed by future versions of the game. No digital system can guarantee absolute security.

## 7. Policy Changes

This policy may be updated as the project develops. The latest version will be published in this repository.

## 8. Contact

For privacy questions, please contact the project maintainer through the GitHub repository:

https://github.com/humanearthsurvival3141-lgtm/EARTH-SURVIVAL

## 9. Important Notice

This document describes the intended privacy approach for an early-stage game project. It is not a guarantee that every future build will have the same data practices, nor is it legal advice.

Before public release, this policy must be reviewed against the actual data collected by the final game and the laws applicable to its users.
