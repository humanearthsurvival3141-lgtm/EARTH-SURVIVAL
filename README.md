
# EARTH SURVIVAL 🌍

**An open-world survival and exploration game for Android, built with Unity and C#.**

## About the Game

EARTH SURVIVAL is a third-person survival game concept focused on exploration, resource gathering, shelter building, and completing missions.

Explore forests, villages, cities, and mountains while managing your character's health, hunger, thirst, and stamina.

## Core Features

- Third-person exploration
- Open-world environment
- Food and water gathering
- Health, hunger, thirst, and stamina systems
- Shelter and survival mechanics
- Countdown-based missions
- Mission completion and retry
- Checkpoints and level unlocking
- Android-friendly mobile controls
- Save system
- Peaceful survival gameplay with no weapons or combat planned

## Development Status

**Status: Early Development / Prototype**

The project is under development. Features may change as the prototype evolves. A playable Android build has not yet been confirmed.

3. Add missions, checkpoints, and level progression.
4. Improve Android touch controls and performance.
5. Test and validate the game in Unity before release.
